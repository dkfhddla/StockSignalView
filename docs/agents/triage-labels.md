# 트리아지 라벨

공학 스킬이 사용하는 다섯 가지 표준 트리아지 역할을 이 저장소의 실제 GitHub
라벨에 매핑한다.

| 표준 역할 | GitHub 라벨 | 의미 |
|---|---|---|
| `needs-triage` | `needs-triage` | 유지관리자의 평가가 필요함 |
| `needs-info` | `question` | 제보자의 추가 정보를 기다림 |
| `ready-for-agent` | `ready-for-agent` | 요구사항이 충분하며 에이전트가 독립적으로 구현 가능함 |
| `ready-for-human` | `ready-for-human` | 사람의 구현 또는 판단이 필요함 |
| `wontfix` | `wontfix` | 작업하지 않기로 결정함 |

스킬이 표준 역할을 언급하면 이 표의 GitHub 라벨 문자열을 사용한다.
