# StockSignalView 반응형 기준

## 기본 방향

StockSignalView는 PC에서는 비교와 반복 확인을, 모바일에서는 빠른 상태 확인과 간단한 입력을 우선한다.

## 데스크톱

데스크톱은 표 중심 화면을 기본으로 한다.

### 우선순위

- 여러 종목을 한 번에 비교한다.
- 정렬과 필터를 빠르게 사용한다.
- 평가손익, 상대수익률, 알림 상태를 같은 행에서 확인한다.
- 상세 정보는 행 선택 또는 상세 화면으로 이동해 확인한다.

### 레이아웃

- 대시보드는 상단 요약, 필터 바, 데이터 표, 보조 패널 순서로 구성한다.
- 표는 가로 공간을 사용하되 중요도가 낮은 컬럼은 숨기거나 접을 수 있어야 한다.
- 종목 상세는 성과 요약과 거래 타임라인을 나란히 둘 수 있다.

## 태블릿

태블릿은 표와 카드가 섞일 수 있는 중간 화면이다.

### 우선순위

- 대시보드는 축약 표 또는 넓은 카드 목록을 사용한다.
- 상세 화면은 단일 컬럼에 가까운 구성을 사용한다.
- 필터와 주요 액션은 화면 상단에 고정하지 않아도 되지만 쉽게 재접근 가능해야 한다.

## 모바일

모바일은 카드 중심 화면을 기본으로 한다.

### 우선순위

- 한 종목의 현재 상태를 빠르게 읽는다.
- 상세 값은 탭 또는 접힘 영역으로 이동한다.
- 새 거래 추가, 현재가 입력, 메모 추가 같은 주요 액션을 손쉽게 시작한다.

### 카드 정보 순서

1. 종목명과 시장
2. 평가손익
3. 상대수익률
4. 알림 상태
5. 최근 메모

## 축소 규칙

- 모든 컬럼을 모바일에 억지로 유지하지 않는다.
- 모바일에서는 평가금액, 평균 매수가, 시장 수익률 같은 보조 값은 상세 화면으로 이동한다.
- 긴 메모는 한두 줄로 줄이고 상세 화면에서 전체를 보여준다.
- 숫자는 줄바꿈으로 의미가 깨지지 않게 한다.

## 터치 조작

- 주요 버튼은 손가락으로 누르기 쉬운 크기를 유지한다.
- 행 전체 또는 카드 전체를 상세 이동 대상으로 사용할 수 있다.
- 삭제와 위험 액션은 실수 방지를 위해 확인 절차를 둔다.

## 빈 상태와 오류

모든 화면 크기에서 빈 상태와 오류 상태가 레이아웃을 깨지 않아야 한다.

### 공통 상태

- 종목 없음
- 거래 없음
- 현재가 없음
- 시장 지수 없음
- 상대수익률 계산 불가
- 알림 조건 없음

## 검증 기준

- 데스크톱에서 보유 종목 표가 주요 정보를 한 화면에서 비교할 수 있다.
- 모바일에서 종목 카드가 한 화면에 최소 2개 이상 자연스럽게 보인다.
- 버튼과 배지의 텍스트가 잘리지 않는다.
- 주요 숫자가 서로 겹치거나 줄바꿈으로 의미가 깨지지 않는다.
- 계산 불가 상태가 빈 값처럼 오해되지 않는다.
