# StockSignalView 디자인 시스템 기준

## 시각 방향

StockSignalView는 개인 투자자의 운영 도구다. 화면은 조용하고 밀도 있게 구성하며, 반복 확인과 비교에 적합해야 한다.

마케팅 페이지처럼 큰 히어로, 장식적 카드, 과한 그래디언트를 사용하지 않는다. 첫 화면은 실사용 대시보드다.

## 레이아웃

- 데스크톱은 최대한 표와 패널 중심으로 구성한다.
- 모바일은 종목 카드와 하단 또는 상단 주요 액션 중심으로 구성한다.
- 페이지 섹션은 넓은 밴드 또는 일반 레이아웃으로 구성하고, 카드 안에 카드를 넣지 않는다.
- 도구 영역, 필터, 요약 영역은 화면 이동 없이 빠르게 스캔되도록 배치한다.

## 간격

- 기본 간격 단위는 4px 또는 8px 배수를 사용한다.
- 데이터 표와 폼은 과도하게 넓은 여백을 피한다.
- 반복 항목의 높이는 안정적으로 유지한다.
- 숫자와 라벨은 서로 붙지 않게 하되, 비교해야 하는 값은 가까이 둔다.

## 모서리와 테두리

- 카드와 패널의 기본 radius는 8px 이하로 둔다.
- 입력, 버튼, 표 행의 hover 상태는 레이아웃을 흔들지 않아야 한다.
- 테두리는 정보 구분을 위해 사용하고 장식용 중첩 테두리는 피한다.

## 색상

색상은 수익/손실, 강세/약세, 상태를 구분하기 위한 보조 수단이다. 색만으로 의미를 전달하지 않는다.

### 의미 색상

- 수익: 긍정 상태
- 손실: 부정 상태
- 상대 강세: 시장 대비 우위
- 상대 약세: 시장 대비 열위
- 경고: 알림 조건 충족 또는 데이터 주의
- 중립: 데이터 없음, 관망, 비활성

### 사용 원칙

- 평가손익 색과 상대수익률 색은 같은 팔레트를 쓸 수 있지만 라벨과 배지로 의미를 분리한다.
- 강한 원색 배경은 주요 경고나 액션에만 제한한다.
- 단일 색 계열만으로 전체 UI를 구성하지 않는다.

## 타이포그래피

- 본문과 데이터 표는 작은 크기에서도 읽기 쉬운 sans-serif를 사용한다.
- 큰 제목은 페이지나 주요 화면 제목에만 사용한다.
- 표, 카드, 사이드바 안의 제목은 작고 명확하게 둔다.
- 글자 간격은 기본값을 사용한다.
- 뷰포트 너비에 따라 글자 크기를 직접 비례 확대하지 않는다.

## 숫자 표현

- 금액은 우측 정렬한다.
- 수량과 가격은 단위와 함께 일관되게 표시한다.
- 퍼센트 값은 `+`, `-`, `%`를 명확히 표시한다.
- 계산 불가 값은 `-`만 두지 않고 가능한 경우 원인을 함께 제공한다.

## 차트와 시각화

MVP의 차트는 보조 요소다. 표와 수치가 먼저이고, 차트는 추세를 빠르게 읽는 용도로 사용한다.

### 권장 차트

- 종목 수익률과 시장 수익률 비교 선형 차트
- 상대수익률 변화 작은 추세선
- 포트폴리오 비중 막대 또는 리스트

### 금지

- 근거 없는 예측선을 확정 정보처럼 표현하지 않는다.
- AI 요약이나 뉴스 분석이 없는 MVP에서 복잡한 분석 차트를 먼저 배치하지 않는다.

## 아이콘과 액션

- 편집, 삭제, 저장, 필터, 정렬, 새로고침 같은 도구성 액션은 아이콘 버튼을 우선한다.
- 익숙하지 않은 아이콘에는 툴팁을 제공한다.
- 주요 생성 액션은 텍스트 버튼 또는 아이콘과 텍스트를 함께 사용한다.
- 위험 액션은 색, 라벨, 확인 절차를 함께 사용한다.
